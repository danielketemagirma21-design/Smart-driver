# 🚗 Smart Driver - Traffic Monitoring & Driver Expense Minimization System

## 📌 Project Overview

**Smart Driver** is a comprehensive web-based platform designed to monitor traffic activity and minimize driver expenditure and traffic penalties. The system helps drivers track their violations, monitor fuel consumption, report road conditions, and receive notifications to improve their driving behavior.

### 🎯 Key Features

#### For Drivers
- ✅ **User Registration & Login** - Secure authentication system
- ✅ **Dashboard** - View driver score, violations, and fuel statistics
- ✅ **Violation Tracking** - View all traffic violations with details
- ✅ **Fuel Records** - Track fuel consumption and efficiency
- ✅ **Road Reports** - Report road conditions, accidents, and traffic jams
- ✅ **Notifications** - Receive alerts for violations, approvals, and system updates
- ✅ **Profile Management** - Update personal information and change password
- ✅ **Driver Scoring System** - Earn points for safe driving

#### For Admins
- ✅ **Admin Dashboard** - Overview with charts and statistics
- ✅ **User Management** - View, block, activate, or delete users
- ✅ **Violation Management** - Verify, reject, or delete violations
- ✅ **Fuel Management** - View all fuel records with statistics
- ✅ **Report Management** - Approve or reject road reports
- ✅ **System Settings** - Configure fuel prices, penalty periods, and more
- ✅ **Activity Logs** - Track all admin actions
